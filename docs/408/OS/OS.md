# 第一章：计算机系统概述  
  
## 操作系统的概念，功能和目标  
### 概念（定义）  
 负责管理协调硬件，软件等计算机资源的工作；  
 为上层用户，应用程序提供简单易用的服务；  
 是一种系统软件。  
  
### 功能和目标  
#### 资源的管理者  
处理机管理，存储器管理，文件管理，设备管理。  
  
#### 向上层提供服务  
##### 给普通用户用的  
###### GUI 用户图形界面  
###### 命令接口  
联机命令接口，脱机命令接口  
  
##### 给软件/程序员用的  
程序接口（即，系统调用）  
  
#### 对硬件机器的扩展  
扩充机器
